# Поле чудес — локальная ведущая студия

Одномашинное браузерное приложение для ведения игры в стиле «Поле чудес» на общем экране.

## Запуск

1. Установите зависимости:

```bash
npm install
```

2. Запустите локальный сервер:

```bash
npm run dev
```

3. Откройте в браузере:

- `http://localhost:5173/display.html` — публичный дисплей.
- `http://localhost:5173/host.html` — панель ведущего.

> Совет: используйте экран ноутбука для панели ведущего, а внешний монитор — для публичного дисплея.

## Подключение ведущего с телефона

Сервер слушает `0.0.0.0`, поэтому приложение доступно по адресу `http://<локальный-ip>:5173`.

На панели ведущего:

1. Откройте блок «Подключение по сети». Там показан URL и QR-код.
2. Отсканируйте QR-код на телефоне и откройте `/host.html`.
3. Дисплей продолжает получать только маску загадки и открытые буквы.

> QR-код генерируется через публичный API и требует доступ в интернет для загрузки изображения.

## Быстрый сценарий проведения раунда

1. Введите категорию и текст загадки, нажмите «Установить загадку».
2. Нажмите «Крутить барабан».
3. Введите букву и нажмите «Назвать букву».
4. При необходимости вручную начисляйте очки или применяйте «Банкрот»/«Переход хода».
5. Используйте «Загадка решена», чтобы завершить раунд.

## Импорт загадок

Поддерживаются CSV и JSON.

**CSV**

```csv
category,puzzle,hint
Животные,БЕЛЫЙ МЕДВЕДЬ,Живёт в Арктике
```

**JSON**

```json
[
  { "category": "Животные", "puzzle": "БЕЛЫЙ МЕДВЕДЬ", "hint": "Живёт в Арктике" }
]
```

## Оффлайн-режим

После первой загрузки приложение работает без сети в рамках одного устройства через `BroadcastChannel`.
Для удалённого управления по сети требуется запущенный локальный сервер.
